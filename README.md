# Flight Price Prediction Using PySpark

## Project Overview
A machine learning project that predicts flight ticket prices based on airline, source city, destination city, travel duration, number of stops, and other travel-related features.

## Technologies Used
- Python
- PySpark
- Machine Learning
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Machine Learning Models
### Supervised Learning
- Linear Regression
- Decision Tree Regression

### Unsupervised Learning
- K-Means Clustering
- Bisecting K-Means

## Model Evaluation
Models were evaluated using RMSE, MAE, R² score, and Silhouette Score.

## Project Files
- Jupyter Notebook: Complete implementation and analysis.

## Objective
To analyze flight-related data and develop machine learning models for flight price prediction.
